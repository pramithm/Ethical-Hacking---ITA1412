## 📘 About

This repository documents the practical lab work carried out as part of the **ITA1412 – Ethical Hacking** course. Each experiment includes the **aim, tools used, theory, step-by-step procedure, commands executed, and output screenshots**, formatted as individual Word (`.docx`) lab reports for easy review and submission.

All experiments were performed in a **controlled, isolated lab environment** using Kali Linux against designated target machines (e.g. Metasploitable) strictly for academic and educational purposes.


